# Python Calculator

Простой калькулятор на Python с графическим интерфейсом Tkinter.

## Возможности

- Сложение
- Вычитание
- Умножение
- Деление
- Обработка деления на ноль

## Запуск

```bash
python app.py
```
## Запуск тестов
```bash
python -m unittest discover -s tests -v
```
## CI
Для проекта настроен GitHub Actions. При отправке изменений в репозиторий автоматически выполняются проверка синтаксиса и unit-тесты.
